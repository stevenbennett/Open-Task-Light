# Openness & Licensing

The Open Task Light is an open-source project. The design process has been documented publicly from early prototypes through the finished kit, and project files are being published so you can make replacement parts, modify your light, or use the project as a starting point for your own ideas.

Unless otherwise noted, files published in the Open Task Light GitHub repository are available under the MIT License. You’re welcome to use, modify, and build on them in accordance with the terms of the license.

## Important design constraint

{% hint style="warning" %}
**The horizontal arm is intentionally non-reversible.** This is a deliberate constraint related to the patent landscape surrounding this type of mechanism. Proposals to make the arm reversible will not be accepted into this project.
{% endhint %}

Project files and documentation may continue to be added or updated over time.
