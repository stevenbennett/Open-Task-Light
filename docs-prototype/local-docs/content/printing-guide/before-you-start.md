# Before You Start Printing

The Open Task Light uses tight-fitting hardware and printed features. Check the dimensional accuracy of each filament and print profile before committing to the full set of parts.

1. Print the [Hardware Fit Tester](/open-task-light/printing-guide/before-you-start/hardware-fit-tester.md) using the filament and settings planned for the main parts.
2. Test the M2 square nut, M3 square nut, and M5 screw fits.
3. If the hardware fits correctly, continue with the rest of the Printing Guide.
4. If any fit is too tight or too loose, follow [Correcting Filament Flow](/open-task-light/printing-guide/before-you-start/filament-flow-calibration.md), then print and check the tester again.

{% hint style="info" %}
Repeat this check using the carriage filament and [Carriage Body print settings](/open-task-light/printing-guide/carriage/carriage-body.md). A filament or print-profile change can affect dimensional accuracy.
{% endhint %}

**A note on printing in PETCF:** this material is really nice and strong, but it is genuinely hard to print. Even if you're just printing the carriage in this material you may need to dry the filament first and spend some time dialing it in. If you're struggling you can get a [printed PETCF carriage from me](https://opentasklight.com/products/petcf-carriage). Even though I've printed a bunch of these, I still run into issues. It's fussy stuff. Take your time!
