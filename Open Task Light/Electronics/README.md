# Open Task Light Electronics

Design source, bills of materials, and manufacturing files for the custom PCBs used in the Open Task Light.

## Available files

- [Power Track](Power%20Track/) - Fusion source, Gerber and drill files, and a component BOM for ordering and assembling the Power Track PCB.
- [Power Link](Power%20Link/) - Fusion source, Gerber and drill files, a component BOM, and pick-and-place exports for ordering and assembling the Power Link.

## Coming later

- Control Board

For fabrication guidance and assembly instructions, see the [Custom Manufactured Parts section](https://open-task-light.gitbook.io/open-task-light/self-sourcing-guide/custom-manufactured-parts) of the Open Task Light GitBook. Check the guide before ordering boards or assembling the electronics.
