# Intermittent power dropouts

If the light works while stationary but cuts out when you move it, start with [Check carriage tightness](/open-task-light/usage/maintenance.md#check-carriage-tightness). Loose wheels can interrupt contact between the carriage pins and either power track.

After adjusting, reconnect power, turn the light on, and slowly move it through the full range of both axes.

If it still cuts out, note whether it happens:

* While moving along the vertical rail, the horizontal rail, or both.
* At the same position each time.
* When you gently check the carriage or arm for play.

Unplug the lamp and inspect the tracks for dirt or residue. Follow [Clean the power tracks](/open-task-light/usage/maintenance.md#clean-the-power-tracks), let them dry completely, then test again. If the problem remains, share those observations when [asking for help](/open-task-light/troubleshooting.md#still-need-help).
