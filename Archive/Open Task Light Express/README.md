# Open Task Light Express

> [!IMPORTANT]
> Open Task Light Express is an archived community project based on an earlier version of the Open Task Light. It's preserved for reference and to retain the work and contributions of its original contributors, but it isn't actively maintained and isn't compatible with the current Open Task Light design, parts, or assembly instructions. This variant of the project was a way to use a battery powered LED on the end of the horizontal arm as a quick and affordable way to build an Open Task Light-style lamp.

The Open Task Light Express is the more approachable, completely customizable variant of the Open Task Light project. The Express is constructed from a simplified parts list which includes an out-of-the-box lighting and electronics solution. Check out the project video for a full overview: [https://www.youtube.com/watch?v=xv9rY6r6liI](https://www.youtube.com/watch?v=xv9rY6r6liI)
