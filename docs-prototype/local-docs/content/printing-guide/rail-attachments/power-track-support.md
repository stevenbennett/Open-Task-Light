{% hint style="info" %}
This part requires good dimensional accuracy. If your printer is over or under-extruding you won't be able to insert the track support behind the power tracks. Check the printer with the [Hardware Fit Tester](/open-task-light/printing-guide/before-you-start/hardware-fit-tester.md), [correct the filament flow](/open-task-light/printing-guide/before-you-start/filament-flow-calibration.md) if needed, then print a test piece to measure with calipers. The power track support should be 2.5-2.6 mm tall.
{% endhint %}
