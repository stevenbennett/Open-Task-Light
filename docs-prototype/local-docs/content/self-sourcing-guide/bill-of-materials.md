# Bill of Materials

Choose the bill of materials for the version of the Open Task Light you want to build.

Each list covers the parts and materials you need to source for a complete Open Task Light, not just the base. Parts you need to print are covered separately in the main [Printing Guide](/open-task-light/printing-guide.md) and [Additional Printed Parts](/open-task-light/self-sourcing-guide/additional-printed-parts.md).
