# Usage

{% hint style="danger" %}
Use the Open Task Light only in a dry, indoor environment. It is not water-resistant and must not be exposed to water, splashes, condensation, or other moisture. Dusty environments are also not recommended because dust can accumulate on the exposed power tracks and moving components.
{% endhint %}

See [Safety](/open-task-light/project-information/safety.md) before operating the light and [Maintenance](/open-task-light/usage/maintenance.md) for cleaning guidance.
