# Copper LED Bracket

This directory contains the DXF for manufacturing the copper LED bracket.

The part is intended to be laser cut from C110 copper. Services such as [SendCutSend](https://sendcutsend.com/) and [OSH Cut](https://oshcut.com/) can quote the part directly from the DXF.

- [Download the DXF](copper-led-bracket.dxf)
- [View manufacturing guidance in GitBook](https://open-task-light.gitbook.io/open-task-light/self-sourcing-guide/custom-manufactured-parts/copper-led-bracket)

Review the material, thickness, forming, and other specifications in GitBook before ordering the part. The DXF alone does not define the complete finished part.
