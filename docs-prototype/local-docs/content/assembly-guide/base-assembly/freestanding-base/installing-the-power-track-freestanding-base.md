# Installing the power track (freestanding base)

This step requires an assembled freestanding base. Make sure you've completed the [Assembling the freestanding base](/open-task-light/assembly-guide/base-assembly/freestanding-base/assembling-the-freestanding-base.md) section before continuing on.

### Gather the following

* **Assembled freestanding base** (from previous step)
* **Power track** (1x)
* **M3 set screw** (threaded into the power track before shipping)
* Printed parts
  * [Power Track Support](/open-task-light/printing-guide/rail-attachments/power-track-support.md)(x2)
  * [Power Track Offset Tool](/open-task-light/printing-guide/tools/power-track-offset-tool.md)

Tools:

* **1.5 mm hex driver**

***

### Insert the power track

Find the rail channel where the power cable resides (this photo has the bracket cover piece removed but you can do this with this piece installed).

<figure>
<img src="/images/4c1175ac551f.jpg" alt="Finger pointing at the rail channel on the freestanding base where the power cable sits, with the bracket cover ring removed beside it">
<ol class="callouts">
<li dot="53,37" label="28,18" match="rail channel">Rail channel <note>The channel facing the camera. The base's power cable already sits in it; the power track slides in on top.</note></li>
<li dot="84,30" label="80,8" match="bracket cover piece" link="Print guide: printing-guide/freestanding-base/bracket-cover">Bracket cover <note>Shown removed for the photo only. You can do this step with it installed.</note></li>
</ol>
</figure>
At the top of the rail, insert the power track connecter end first into the same rail channel as the power cable.

⚠️ Friendly reminder: the cable connectors on the power track are fragile. Don't use these to move the board around; always use the board edges.

<figure>
<img src="/images/6e89f6784336.jpg" alt="Hand lowering the power track PCB into the top of the vertical rail, connector end first">
<ol class="callouts">
<li dot="50,15" label="25,15" qty="1" link="Part page: self-sourcing-guide/custom-manufactured-parts/power-track">Power track <note>Hold it by the board edges, never by the connectors.</note></li>
<li dot="50,45" label="25,52" qty="Goes in first" match="connecter end first">Connector end <note>The fragile cable connectors are on this end. It leads into the rail.</note></li>
<li dot="51,33" label="72,45">Rail channel <note>The same channel the power cable runs through.</note></li>
</ol>
</figure>
Once the power track is submerged in the rail by a few inches, insert your first power track spacer with the printbed side of the spacer touching the smooth back of the power track PCB.

<figure>
<img src="/images/c4df4b5c85a2.jpg" alt="First printed power track spacer being pressed onto the back of the power track at the top of the rail">
<ol class="callouts">
<li dot="45,36" label="20,32" qty="1st of 2" match="power track spacer" link="Print guide: printing-guide/rail-attachments/power-track-support">Power track support <note>The printed spacer (the Power Track Support print). The printbed (flat) side faces the power track.</note></li>
<li dot="44,14" label="20,12">Smooth back of the power track PCB <note>Insert the spacer against this side, not the side with the copper tracks.</note></li>
</ol>
</figure>
Slide the spacer and the power track down until you have room to insert the second printed spacer. Push the spacer as far down as possible before sliding the power track all the way down.

<figure><img src="/images/9f7f05ad1cf8.jpg" alt=""></figure>

### Set the power track height

At the base of the lamp, place the power track offset tool (freestanding base version) under the power track to set the height.

<figure>
<img src="/images/6e926ee13cf1.jpg" alt="Hand holding the freestanding base version of the power track offset tool next to the bottom of the power track">
<ol class="callouts">
<li dot="46,47" label="18,40" qty="1 printed" link="Print guide: printing-guide/tools/power-track-offset-tool">Power track offset tool <note>Freestanding base version. Slides under the bottom of the power track, where the rail meets the base, to set its height.</note></li>
<li dot="48,24" label="22,18">Power track <note>Slide it down until it rests on the tool. Leave the tool in place until the set screw is tightened.</note></li>
</ol>
</figure>
<figure><img src="/images/53d671329ed6.jpg" alt=""></figure>

### Secure the power track

Use a 1.5 mm hex driver to secure the power track in place. Finger tighten.

<figure>
<img src="/images/360f118a8f1b.jpg" alt="1.5 mm hex driver tightening the M3 set screw on the power track through the rail channel">
<ol class="callouts">
<li dot="30,47" label="32,68" qty="Tool" link="Tools list: start-here/tools-youll-need">1.5 mm hex driver <note>Its tip is in the M3 set screw that comes threaded into the top of the power track. Finger tighten only; over-tightening can crack the PCB.</note></li>
</ol>
</figure>
Carefully remove the offset tool at the base of the lamp.

Extract the power cable from the rail channel if needed (tweezers work well for this).

<figure><img src="/images/502af145f2aa.jpg" alt=""></figure>

Plug the base into the power track.
