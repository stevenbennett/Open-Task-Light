# Lamp won't turn back on

If the lamp was working but now won't respond to the power button, the QT Py may be stuck in a state that needs a clean reboot.

Start with the [clean power cycle](/open-task-light/troubleshooting.md#start-with-a-clean-power-cycle). This usually gets it responding again.

If the light turns on, you're all set. If this keeps happening, [let me know](/open-task-light/troubleshooting.md#still-need-help) what was happening before it stopped responding.

If the LED flashes but still doesn't respond to the button, [ask for help](/open-task-light/troubleshooting.md#still-need-help) and mention that it flashes.

If it doesn't light up at all, [check carriage tightness](/open-task-light/usage/maintenance.md#check-carriage-tightness) next. If that doesn't help, follow the [multimeter checks](/open-task-light/troubleshooting/no-light-after-assembly.md#set-up-the-multimeter) to see where power stops reaching the lamp.
